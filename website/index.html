A familiar room

Same panels, same dialogs, same modifier keys. All running natively on your desktop.

Everything you reach for, where you left it

Fidelity over reinterpretation: tools behave like the originals, right down to modifier keys.

Layer engine & styles

Raster and vector layers, groups, clipping and layer masks, Smart Objects with non-destructive smart-filter stacks, plus all ten Photoshop layer styles rendered 1:1.

The complete toolset

Marquee, Lasso, Magic Wand, Brush, Clone Stamp, Healing, Gradient, Dodge & Burn, Pen, Type and Shapes: with rulers, guides, pixel grid and a deep History palette with snapshots.

Filters, accelerated

The classic Filter Gallery with live thumbnails, Liquify mesh warping and Lensfun-backed lens correction: image processing compiled to WebAssembly and rendered on WebGL.

Real typography

OpenType ligatures and kerning, HarfBuzz shaping, FriBidi bidirectional layout, type along path and text warp: with full character and paragraph palettes.

Automation & plugins

Play back Photoshop Actions (.atn), script the editor in JavaScript/JSX, and extend it with sandboxed sidebar plugins written in plain HTML, CSS and JS.

Yours, offline

A Tauri v2 desktop app with a Rust host for files, native menus and printing. No account, no cloud, no telemetry: your images never leave your machine.
